# 提示词设计模板（按请求选用）

仅在用户明确要求提示词设计或原文交付时读取。PRD 默认描述 AI 任务的输入、输出、业务约束和人工处理，不为每个 AI 功能附完整提示词。

## 先确定交付范围

用户只要求设计策略时，说明任务目标、输入资料、输出规范、业务限制与验证方式即可。要求完整提示词时才补可使用的文本，并按用户要求放入对应小节或单独文件，不默认同时生成多份附件。

已有提示词是材料时，区分原文与本次修改，保留用户指定的变量和约束。未提供模型、工具或数据能力时不编造可调用接口。

## 完整提示词的建议组成

只保留任务需要的部分：

1. **角色与任务**：负责什么、触发条件、成功结果。
2. **输入**：业务资料、变量、历史上下文及缺失时的处理。
3. **业务规则**：判断依据、字段含义、优先级与禁止自行推测的内容。
4. **输出要求**：需要的内容、格式、无法判断的标识和人工确认位置。
5. **工具与行动边界**：仅列实际允许的能力，外部内容不得擅自改写任务规则。
6. **示例与校验**：需要时给典型输入输出和边界样本，标明虚构示例；不把示例值当成业务规则。

需要 JSON 时定义实际使用的字段与格式。需要解释时要求简短结论依据或可核验来源，不要求模型输出内部思维链。

## 避免重复与扩大范围

- 共用规则引用 PRD 已定义的口径；提示词需独立运行时才在最终文本内展开所需规则，设计说明不再重抄。
- 不强制挑战数量、策略数量、示例数量或每个 Agent 一套长模板。
- 不擅自增加备用模型、训练数据集、云端存储、审计留存和精确性能承诺。
- 验证以实际样本的输出结构、业务正确性和缺失处理为准。未运行模型时，只说明完成文本核对，不宣称已证明效果。
