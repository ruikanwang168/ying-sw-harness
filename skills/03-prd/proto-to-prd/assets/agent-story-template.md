# Agent 职责说明模板（按请求选用）

仅在用户明确要求 Agent 说明且材料中确有对应角色时读取。普通 AI 提取、判断或生成按钮无需拆成多个 Agent。以下是产品职责模板，不负责确定技术架构。

## 推荐内容

每个真实 Agent 说明：

- **承担任务**：在什么业务事件下，为谁完成什么结果。
- **输入与上下文**：需要的资料、业务状态、可访问的数据范围。
- **输出与交接**：交付什么、由谁接收、是否需要人工确认。
- **行动边界**：哪些动作可直接执行，哪些只能建议或经人工确认；只有材料明确时列外部工具能力。
- **重要失败**：资料不足、无法判断或交接失败时如何结束或转交，不把成功结果伪造出来。

同一角色多项相近任务可合并，差异写在任务下；不强制场景卡片、代码块故事、工具参数表和“为什么需要这些”重复描述。

## 协作表达

材料确有多 Agent 且交接影响业务时，选择职责表或协作图解释关键交接、人工决策与失败责任。普通模型调用无需画前后端时序。

不要根据协调器、规划器、研究员等常见名称补出角色；未确定的实现拆分留给研发。完整提示词只在用户要求时另按 [提示词模板](prompt-design-template.md) 编写。
