> **说明**：本指南适用于**常规研发需求**（需求描述 + 可选数据与状态 + AC）。若用户要**产品研发需求清单**（页面/交互/五节验收），见 [product-rd-requirements-list-guidelines.md](product-rd-requirements-list-guidelines.md)。二者可并存，勿混用结构。

阅读 [requirements-layers.md](requirements-layers.md)，并遵循 [assets/rd-requirements-template.md](../assets/rd-requirements-template.md)。

## 原则

- **研发需求**回答：功能需求中的能力，在系统中**具体如何实现**。
- 适用于给后端、给研发、集成、接口协作、状态同步、回写、数据落点、跨模块处理等场景。笼统“给开发”需先按输入内容判定：页面字段交互为主转产品研发需求清单；处理/集成为主使用本指南；两者都有则分别输出。
- **需求描述**是主体：用**简要说明**写清本研发需求的**系统能力、覆盖范围、预期结果**；描述关键处理时按公式展开（勿输出模板中的「公式」blockquote）：
  - 当【用户角色】在【页面/模块/场景】执行【关键操作】时，
  - 系统应根据【业务规则/数据规则/权限规则/状态规则/异步处理规则】完成【处理逻辑】，
  - 并返回 / 展示 / 保存 / 更新【结果】。
- **数据与状态**（可选）：用表格说明业务对象、关键字段、读写规则、状态流转、外部交互；多分支、异常、异步或并发处理可在此节或需求描述中补充。
- **验收标准**验证**可验证结果**是否满足**数据、状态、权限、异常、反馈**等要求。
- 可写产品名、模块名；避免无依据的底层技术选型（除非用户要求）。

## 示例：进入 easy-dataset 加工并回写结果

## 研发需求：数据集开发任务 — 加工环境衔接与结果回写

关联功能需求：数据集开发任务管理

### 需求描述

本研发需求实现**天枢数据集开发任务**与 **easy-dataset** 加工环境的衔接与结果回写，覆盖**进入加工、成功回写、失败处理及服务不可用**四类路径。当**数据治理工程师**在**任务详情页**执行**「进入加工」**时，系统应根据**任务绑定规则**完成**含任务 ID 与输入/输出文件集范围的上下文组装**，并更新**任务状态为「加工中」**、**打开 easy-dataset 加工会话**；当**系统**收到 **easy-dataset** 成功回调时，系统应根据**回写规则**将**产出写入已配置的高质量数据集文件集**并保存**「已完成」状态与完成时间**；当加工**失败、超时或服务不可用**时，系统应根据对应规则**记录失败原因或阻断跳转**，**不写入不完整数据集**，并**保留天枢侧已保存配置**。

### 数据与状态

| 业务对象 | 关键字段 | 读写规则 | 状态流转 | 外部交互 / 边界 |
| -------- | -------- | -------- | -------- | --------------- |
| 天枢开发任务 | task_id、输入/输出文件集 ID | 绑定输入范围与输出目标 | 已配置 → 加工中 → 已完成 / 失败 | easy-dataset 会话跳转 |
| 输出文件集 | 产出物标识 | 成功回写时写入 | — | easy-dataset 回调或轮询上报 |

* 健康检查不通过时阻断跳转，天枢侧配置不变。
* 失败/超时不向输出文件集写入不完整数据集。

### 验收标准

#### AC1：进入加工上下文完整

在**任务状态为「已配置」且输入输出配置完整**的前置条件下，  
当**数据治理工程师执行「进入加工」**时，  
系统应产生**含完整上下文的 easy-dataset 会话/跳转及任务状态「加工中」**，  
并满足**easy-dataset 侧无需用户重新选择天枢已绑定输入输出、状态与权限一致**等要求。

#### AC2：成功回写

在**收到加工成功通知且任务 ID 与产出物标识有效**的前置条件下，  
当**系统执行回写处理**时，  
系统应产生**输出文件集写入结果及任务状态「已完成」与完成时间**，  
并满足**任务详情可跳转至输出文件集、数据可追溯**等要求。

#### AC3：失败与不可用

在**加工失败、超时或服务不可用**的前置条件下，  
当**用户或系统触发对应异常分支**时，  
系统应产生**状态更新、阻断跳转或明确提示等可验证结果**，  
并满足**不产生脏数据、不丢失已保存配置、反馈与规则一致**等要求。
