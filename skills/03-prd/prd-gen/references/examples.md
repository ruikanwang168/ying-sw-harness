# 功能粒度示例

## 增量场景

同一「申请延期」规则同时出现在桌面详情和移动详情，合写公共资格和计算。若桌面端允许提交、移动端仅展示结果，分别写入口和结果。清单还应追踪提交后的审批状态与回显、操作记录、相关消息，以及已有批量入口是否受影响。材料缺少审批失败后的状态时，保留该问题及其对验收的影响。

## 复杂新功能

审批功能可以按发起、审批、撤回和查看记录组织。状态表写清操作角色、当前状态、动作和流向。若撤回会取消后台提醒，按撤回的结果核对提醒任务，即使界面上没有对应按钮。普通分页可以统一说明并列出适用列表。若跨页勾选的记录参与批量审批，补齐保留范围、资格校验和部分失败处理。

## 对账示例

「导出订单」同时更新筛选口径与敏感字段权限时，至少核对筛选组合、导出范围、字段权限和失败结果。只写「支持导出」会留下验收缺口。若导出在后台生成文件并发送下载通知，文件生成与通知也各有可观察结果。可将这些规则写在同一处，并从覆盖清单指向该处的具体条文。
