# 运行与截图规范

仅当用户需要运行验证、页面链接或截图证据，且这些证据能提升交付可用性时使用本规范。非页面产品、材料不足或无法安全运行时，不强制截图；如实记录未验证原因和影响。

启动前确认项目路径、版本控制状态、锁文件、启动说明、环境变量名、端口和已有服务。按锁文件选择包管理器，不升级依赖；安装会修改受版本控制文件时先说明影响。只记录本次启动的进程、端口和必要日志。

需要登录、验证码、数据库、外部服务或写入数据时，使用用户授权的测试环境和账号。生产环境默认只读；创建、编辑、删除、审批、发布、支付或发送消息前必须取得明确授权。不要读取、输出或写入凭据。

截图前盘点页面中的按钮、链接、导航、输入、筛选、分页、行操作、弹窗、键盘触发和原型热点。每项归入业务能力、通用交互、非业务交互、待确认或无法安全验证，并记录验证结果。截图只覆盖能证明关键规则、状态、异常或结果的页面，不以数量为目标。

页面型证据使用真实 HTTP(S) 地址；源码路径、`file://`、静态 HTML 和已有图片不能冒充运行验证。PC 使用未缩放的桌面视口，移动端使用真实或仿真的移动视口；同一功能同时支持两端时分别验证。截图保存为相对路径，使用清晰替代文本，并逐张打开检查终端、页面状态与敏感信息。

交付时说明哪些地址已验证、哪些需要登录或无权、哪些无法验证以及原因。支撑交付链接的本地预览服务在交付时保持可用；停止仅为本次验证启动的辅助进程，不清理用户已有服务或文件。
