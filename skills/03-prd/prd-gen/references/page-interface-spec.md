# 页面、控件与接口覆盖标准

本文件规定要回答的问题，不规定 PRD 的章节、表格、编号或表达形式。可按模块、用户任务、页面、流程、领域对象或接口组织，也可组合使用段落、列表、表格和图示。

## 页面覆盖

逐个页面、弹窗和抽屉说明业务入口、适用角色、可见数据范围、数据来源以及实际存在的页面状态。默认、加载、空数据、查询结果、校验失败、无权和系统失败等仅在适用时展开。说明原型、运行页面、截图或源码定位及验证状态。

## 控件覆盖

逐项覆盖按钮、链接、输入框、文本域、单选、多选、选择框、级联选择、日期/时间、开关、上传、查询条件、标签页、表格列、行操作、分页、弹窗控制、键盘触发、只读字段、汇总指标和提示信息。

针对每项，按适用性说明业务用途；数据来源、默认值与格式；显示、必填、只读和编辑条件；长度、精度、范围及单字段/跨字段校验；联动与权限；触发动作；页面反馈；接口调用；成功、失败与恢复结果。通用规则可以引用，但不得让控件本身从覆盖范围中消失。

查询需明确条件、默认值、匹配与组合方式、重置、排序、分页和结果展示。表格逐列明确含义、来源、格式、空值、脱敏、权限及行操作。选择框明确选项来源、加载、搜索、单/多选、级联、失效项和空选项。

## 接口覆盖

逐个页面调用接口、回调、批处理、定时任务或对外能力说明：用途、调用方与触发时机；已有/新增/变更状态；调用形式；请求与响应字段规则；身份、权限、数据范围、对象状态、唯一性和时效性校验；有顺序的处理逻辑；数据读写与状态转换；记录、通知、审批、文件或下游任务等副作用；重复、并发、整体/部分成功、回滚、重试与超时结果；业务异常、页面反馈和恢复动作。

现有接口从代码追踪前端调用、路由/控制器、服务和模型，区分当前实现与目标需求。拟新增接口只定义材料已确认的契约。材料不足时标记待确认，不得猜测。

## 关系与覆盖复核

让每个页面动作都能找到相关接口、页面结果和数据/状态结果；纯前端行为明确无接口。让每个接口都能找到页面、系统任务或外部调用方。

交付前对照材料逐项复核，不以出现某个章节或关键词代替覆盖证明。报告未说明的控件、未追踪的网络调用、无调用方接口、无页面/数据结果操作，以及无法安全验证的项目。
