# 页面说明要求

先盘点交付范围内的页面、弹窗和抽屉，以及每处的入口、角色、数据范围、数据来源和状态。全量需求覆盖这些页面的所有功能行为。增量需求展开变化及其关联行为，并标明依赖的共享规则与适用范围。

盘点按钮、链接、文本输入、单选/多选、选择框、日期时间、开关、上传、查询、标签页、表格列、行操作、分页、弹窗控制、键盘触发、只读展示、指标和提示。逐项核对数据来源与默认值、显示/必填/编辑条件、取值和校验、联动、权限、触发和反馈。共享分页、关闭和加载可合写，列清适用的载体或入口。存在页面、端、角色或业务状态差异时分别说明。

查询按适用情况写查询条件、默认值、匹配方式、条件组合、重置、排序、分页和结果展示。表格关注含义、取值、格式、空值、脱敏和行操作。选择框关注选项来源、加载时机、搜索、单/多选、级联、失效项和空选项。

业务动作的页面反馈、系统结果和验收可以同写在功能条目中。有跨端或跨系统联动时，说明各端何时看到什么结果。具体规则见[业务操作研发契约](operation-contract.md)与[页面、控件与接口覆盖标准](page-interface-spec.md)。
