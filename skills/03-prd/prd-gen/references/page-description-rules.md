# 页面说明要求

逐页面、弹窗和抽屉说明入口、角色、数据范围、布局区域、数据来源和页面状态。逐项记录按钮、链接、输入框、文本域、单选/多选、选择框、日期时间、开关、上传、查询条件、标签页、表格列、行操作、分页、弹窗控制、键盘触发、只读展示项、汇总指标和提示信息。

每个控件写清数据来源与默认值、显示/必填/编辑条件、取值和校验、字段联动、权限、触发动作、页面反馈、调用接口或“无接口—纯前端”。通用分页、关闭、加载等可引用统一规则，但每个实际控件仍需在文档中可定位。

查询规格需覆盖查询条件、默认条件、匹配方式、条件组合、重置、排序、分页和结果展示；表格逐列说明含义、来源、格式、空值、脱敏和行操作；选择框说明选项来源、加载时机、搜索、单/多选、级联、失效项与空选项。

动作说明需回答谁在什么条件下操作，页面如何响应，调用哪个接口，后端完成什么，数据或状态如何变化，失败时如何继续，以及如何验收。详见 [page-interface-spec.md](page-interface-spec.md) 与 [operation-contract.md](operation-contract.md)。
