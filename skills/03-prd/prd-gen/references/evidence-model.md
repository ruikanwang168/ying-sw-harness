# 需求依据模型

对重要结论保留内部定位：结论、类型、来源、定位点、可信度和备注。类型只有：明确事实、合理推断、待确认、冲突。

定位必须可复核：文档使用文件路径与标题/表格行；原型使用 URL、页面或状态；代码使用相对路径与路由、组件、方法或字段；运行页面使用地址、角色、状态和截图路径。

不要把“代码存在”当作目标需求。材料冲突时列出不同描述、影响和待用户裁决；材料不足时说明缺失信息与对范围、设计或验收的影响。完整依据地图是内部分析产物，除非用户要求，不直接进入 PRD 正文。

分析页面或原型时，盘点按钮、链接、导航、输入、筛选、分页、行操作、弹窗、键盘触发和热点。每项归入业务能力、通用交互、非业务交互、待确认或无法安全验证；不要让控件因无事件代码或未点击而消失。
